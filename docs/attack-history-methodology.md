# Attack-history methodology

Searches resolve scheme aliases, earlier names, authors, ePrint identifiers,
predecessors, and successors. Sources include ePrint and formal literature indexes,
standards and competition records, mailing lists and forums, repositories and issue
trackers, slides, theses, technical reports, project pages, archives, and general web
search.

A scheme is excluded when credible prior public work already demonstrates a
substantive attack on that scheme. Analysis of a related scheme or use of a known
technique does not by itself exclude the target. Searches are repeated after any
successful technical result, using the discovered attack mechanism and outcome as
additional terms.

The project uses cautious date-stamped wording: no prior public attack was located in
the searches performed. It does not claim exhaustive knowledge of unpublished work.
